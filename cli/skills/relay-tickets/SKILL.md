# /relay-tickets

This is the Relay skill under a name that can't collide with an organisation's or another plugin's
`relay`. Read `~/.claude/skills/relay/SKILL.md` and follow it. It covers getting a ticket as soon as
the work is clear, `Continue KEY.`, notes from Adam, file logging and the end-of-phase handoff.

The CLI is `~/.claude/relay/bin/relay` (`relay help` lists the commands).
